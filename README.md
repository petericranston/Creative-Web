# Creative Web

## Project Proposal

The web app I am proposing will be an app called MythMapper, in which users will be provided with a map, and they can add their own content on top of it. Such as, locations, roads, characters etc. Adding their own lore and myths to their world. These worlds can then be shared among other creators and users.

Some inspiration and existing alternatives that I have looked at are World Anvil. This webapp has a similar concept to what I am proposing. My web app would serve as a helping hand to a person that wanted to create an entire storyline in a book for example. Explaining to readers where all the characters and location are, while reading along. The end product of what users would create using the tools I create could be similar to the interactive Game Of Thrones map, which I also took some inspiration from on how the worlds could be laid out. 

There will be a few ways in which data will be stored and used. The first of which will be users creating accounts, and logging in and out from them. Their data has to be securely stored, likely encrypted to some extent. Every time a user creates a world, the data has to be stored against their account, so they can continue to work on it whenever they wish. All the users interactive that regard building their map has to be stored, for example, placing locations, roads etc has to be stored using coordinates, and all the other necessary data likely in a JSON file for efficiency. 

I will have to use an API for the creation of the maps, so that the project is in scope. There are a few options to choose from, the best i've found thus far is Leaflet.js. I will also use react to create my front end, as i think this will allow me to make a professional and well rounded web app. I could also use AI image generation to help bring worlds to life, by creating designs for characters, places etc.

There are two sides to the audience of this web app, the first of which is the creators of the worlds. This could be anyone, authors, DnD players, or someone just wanting to create a world that interests them. The other side of the audience is the users that would look and use these interactive maps. Age, gender and race demographics are less important for this project. Users will more than likely be over the age of 16 but other than that it won't be tailored to a demographic.
